# Cascade demo script — target 2:35

## 0:00–0:15 — Hook

Show the hero and say: “A four-hour flight delay is not one calendar edit. It is a chain reaction across pickup, care, deliveries, dinner, work, home automation, and people waiting on you. Cascade recovers the chain.”

## 0:15–0:30 — Explain the model

Point to the context graph and risk model. “Cascade keeps a dependency-aware context, executes reversible changes automatically, and stops before money, cancellations, or external messages.”

## 0:30–1:20 — Run the flight disruption

Click **Run this disruption**. Let the safe steps progress. Call out that the planner parsed the four-hour delay and re-anchored downstream commitments. Show the context graph changing from at-risk to updated and the audit receipt filling in.

## 1:20–1:45 — Human approval boundary

When dinner pauses, explain the consequence and approve it. When the Sam message pauses, point out that an external message cannot be rolled back, then approve it. Let Cascade reach reconciliation.

## 1:45–2:10 — Multi-turn state

Click **Actually, I’ll take a rideshare instead**. Explain: “This is not replaying the original script. Cascade replans from the already-mutated day.” Let the safe changes run and approve the follow-up message.

## 2:10–2:25 — Compensation

In the audit receipt, roll back one reversible transport/calendar action. Show the context item restore while the message action correctly has no rollback control.

## 2:25–2:35 — Close

“Cascade is a simulated Alexa+ experience built around persistent context, an inspectable planner, typed tools, approval gates, honest blocked states, and compensation. One change; the rest of your day recovers.”
